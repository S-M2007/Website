Voting App

Web Dev Full Stack App

An Android application for creating, sharing, and participating in polls and voting sessions — built to be intuitive, fast, and easy to use. Created for the Indian Community Center of Garden State.

Overview

The Voting App is an Android application that allows users to create custom polls, share them with others, and view live results. The goal was to build something genuinely useful while exploring mobile app development.

Features

  • Create custom, timed polls with multiple options
  • Share polls within a community of users
  • Clean, accessible user interface
